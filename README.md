# BA Probability Calculator
Webpage to calculate probability of getting `X` rate up units in `Y` pulls given a starting "Recruitement Charge" of `Z` (and possibly, already consumed `W` mileage)

## Features
- Exact probabilty calculated on the fly through convolution
- Iterative convolution serves to complately crash the browser due to the amount of compute
